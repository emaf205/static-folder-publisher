# Contributing to Static Folder Publisher

Thanks for your interest in Static Folder Publisher.

This is a small, focused open-source project created and maintained by **EmaF205**.

## Before contributing

Please keep the core idea intact:

> Bring your HTML. Organize it in folders. Publish a complete static site.

The project should remain:

- simple
- HTML-first
- file-based
- white-label
- static
- easy to understand
- free from unnecessary CMS-like complexity

## Good contributions

Useful contributions include:

- bug fixes
- clearer documentation
- better tests
- small usability improvements
- safer build behavior
- improvements that preserve source HTML

## Please avoid

The core should not become:

- a CMS
- a visual editor
- an admin dashboard
- a database-driven system
- a server-side application
- a large plugin platform

New ideas are welcome, but they should make publishing through folders simpler.

## How to contribute

1. Open an issue if you want to discuss an idea or bug.
2. Fork the repository.
3. Create a focused branch.
4. Make the smallest useful change.
5. Run the tests.
6. Open a pull request explaining what changed and why.

## Tests

```bash
python -m unittest discover -s tests -v
publisher validate
publisher build
```
