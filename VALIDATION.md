## CI coverage prepared, not yet executed remotely

The GitHub CI workflow is configured for Python 3.10, 3.11, 3.12, 3.13 and 3.14. Only Python 3.13.5 is available in the current local runtime, so the other interpreter versions are **not claimed as executed** until the repository is pushed and GitHub Actions completes successfully.

## Intentional V1 boundary

Finished HTML pages remain user-owned and are copied byte-for-byte. Automatic navigation and breadcrumbs are generated for structural pages only; V1 does not inject shared markup into source HTML.

`index=false` controls generated listings/RSS, not search-engine indexing: the directly accessible page remains in the sitemap.

## Link-validation boundary

V1 checks common HTML `href` and `src` references. It does not attempt to crawl external URLs, execute JavaScript, parse CSS `url()` references, or prove availability of routes handled outside the generated static tree.
